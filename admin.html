Admin Control Panel

ডেমো সংস্করণের সীমাবদ্ধতা: এই সংস্করণে Admin Panel-এর পরিবর্তন একই ব্রাউজারের Local Storage-এ সেভ হয়। লাইভ ওয়েবসাইটে সবার জন্য পরিবর্তন প্রকাশ, নিরাপদ Admin Login এবং Customer Dashboard-এর বাস্তব ডেটার জন্য পরবর্তী ধাপে Supabase/Backend যুক্ত করতে হবে। Public সাইটে এই Demo Admin লিংক নিরাপদ লগইন ছাড়া প্রকাশ করবেন না।
